# 📋 To-Do List

Aplicação web de lista de tarefas desenvolvida com **HTML, CSS e JavaScript**, permitindo o gerenciamento simples de atividades do dia a dia.

## Funcionalidades

- ➕ Adicionar novas tarefas
- 🏷 Adicionar tags às tarefas
- 🔍 Pesquisar tarefas pelo nome
- 🔖 Filtrar tarefas (todas, concluídas e pendentes)
- ✏️ Editar tarefas existentes
- 🗑 Remover tarefas
- 💾 Persistência de dados no **LocalStorage**

---

## Tecnologias utilizadas

- **HTML5** → estrutura da aplicação  
- **CSS3** → estilização e responsividade  
- **JavaScript** → lógica, eventos e manipulação do DOM  
- **LocalStorage** → armazenamento das tarefas no navegador
